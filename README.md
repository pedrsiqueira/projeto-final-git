## Sobre o Projeto

Este repositório consolida o **Projeto Integrador Final** do minicurso de **Git e GitHub**.

A aplicação consiste em uma página web estática de portfólio pessoal (`index.html` e `style.css`), construída e versionada sob práticas profissionais de engenharia de software: planejamento orientado a *Issues*, isolamento de funcionalidades por *branches* temáticas, histórico padronizado com *Conventional Commits*, integração via *Pull Requests* e hospedagem contínua pelo *GitHub Pages*.

---

## Arquitetura do Repositório

* **`index.html`** — Estrutura semântica do portfólio (sobre, habilidades, projetos e contato).
* **`style.css`** — Folha de estilos com tema escuro, grid responsivo e variáveis CSS.
* **`README.md`** — Documentação principal do projeto.
* **`reflexao.md`** — Análise crítica sobre versionamento, colaboração e aprendizado no curso.

---

## Fluxo de Trabalho & Versionamento

O desenvolvimento foi dividido em etapas independentes para manter a branch `main` estável durante todo o ciclo:

1. **Inicialização (`main`):** Configuração do repositório local, vínculo remoto e abertura das Issues `#1` a `#4`.
2. **Estruturação (`feat/estrutura-portfolio`):** Desenvolvimento do esqueleto HTML5 com as seções de apresentação, stack técnica e vitrine dos repositórios do curso (`Closes #1`).
3. **Estilização (`style/css`):** Implementação da identidade visual, sistema de cards em grid e adaptação para dispositivos móveis (`Closes #2`).
4. **Documentação (`docs/readme`):** Criação desta documentação técnica com capa, badges, tabelas e links (`Closes #3`).
5. **Reflexão (`docs/reflexao`):** Registro analítico sobre o domínio do Git local e fluxos colaborativos no GitHub (`Closes #4`).
